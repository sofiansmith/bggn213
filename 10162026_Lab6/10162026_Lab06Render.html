Background

All functions have at least 3 things:

  • a name (we get to pick this)
  • inout arguments (one or more separated inputs)
  • the body (the lines of the R code that do work of the function)

A first function

Let’s write a function to add to some numbers

add <- function(x, y=0) {
  x + y
}

We can test it out!

add(1, 100)
[1] 101
add(c(1,2,10), 100)
[1] 101 102 110

Function arguments can be required or optional. This just means that opitionals have a default fallback value thats used if the user does not supply one. (like our y input above, or z below)

What if I wanted to run out add() function with three inputs?

add <- function(x, y=0, z=0) {
  x + y + z
}
add(1,20,100)
[1] 121
add(1,20)
[1] 21

R also can take any number of inputs that you don’t have to spell out like our x y and z, via an elipse ... used as a catch-all input argument.

We can explicitly return a value from a function with the special function return. It is often a good thing to use to keep the function clean, even if you don’t think you need it.

A DNA sequence generator

Write a wee function to generate a random nucleotide sequence of a user specified length.

A useful function to start with is the sample() function.

sample(x = c("A","G","C","T"), size=7, replace=TRUE)
[1] "A" "A" "C" "A" "G" "C" "G"

Make sure that you set replace=True if your sample is more than your input pool!!

This is our working “snipet” of code that does what we want so lets make it a function.

generate_dna <- function(seqlength){
  sample(c("A", "G", "C", "T"), size=seqlength, replace=T)
}
x <- generate_dna(7)
x
[1] "G" "T" "C" "C" "G" "G" "T"

Now that’s great, but they’re all separated and I can’t copy/paste them :/

Optional format switch

Rn we’re getting a multi-element character vector, which is not all that great for some things. Maybe I want “GGTGAACTA”!

So we’re going to use the function paste()

paste(x, collapse = "")
[1] "GTCCGGT"
paste(x)
[1] "G" "T" "C" "C" "G" "G" "T"

So if we put it all together, it might look like this:

generate_dna <- function(seqlength){
  n <- sample(c("A", "G", "C", "T"), size=seqlength, replace=T)
  paste(n, collapse="")
}

And now to create my n-long DNA sequence:

generate_dna(25)
[1] "ATTGACAATCAACTCGTATTAAGCA"

We want to allow the user to pick the format, for this we can use a T/F + if/else kind of input argument…

generate_dna <- function(seqlength=25, fasta=TRUE){
  n <- sample(c("A", "G", "C", "T"), size=seqlength, replace=T)

  if(fasta) {
    paste(n, collapse="")
  } else {
    paste(n)
  } 
}

you could also do this without if AND else, just an explicit return().

generate_dna <- function(seqlength=25, fasta=TRUE){
  n <- sample(c("A", "G", "C", "T"), size=seqlength, replace=T)

  if(fasta) {
    n <- paste(n, collapse="")
  } 
  return(n)
}

In this one, you just return n in it’s original format bc the if didn’t run to rewrite n.

seq <- generate_dna(6, fasta=TRUE)
seq
[1] "TTGATT"
seq <- generate_dna(6, fasta=FALSE)
seq
[1] "T" "C" "C" "A" "A" "T"

We want the FASTA format that everyone uses though.

generate_dna <- function(seqlength=25, fasta=TRUE){
  n <- sample(c("A", "G", "C", "T"), size=seqlength, replace=T)

  if(fasta) {
    id <- paste(">len", seqlength)
    n <- paste(n, collapse="")
    
    cat(id, n, sep = "\n")
  } 
  return(n)
}
x <- generate_dna(25,T)
>len 25
GCGCTAAGGTTTTGCGATACCACAT

Generate a protein sequence

Q. Write a function called generate_protein() that returns a random aa sequence of a user specified length in FASTA format

generate_protein <- function(seqlength=25, fasta=TRUE){
  n <- sample(c("A", "R", "N", "D", "C", "Q", "E", "G", "H", "I", "L", "K", "M", "F", "P", "S", "T", "W", "Y", "V"), size=seqlength, replace=T)
 
  if(fasta) {
    id <- paste(">len", seqlength)
    n <- paste(n, collapse="")
    
    cat(id, n, sep = "\n")
  } 
  return(n)
}
